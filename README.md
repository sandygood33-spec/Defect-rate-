# 零件耗用 / 故障率查詢工具

## 部署到 Streamlit Community Cloud（免費、給同事一個網址用）

1. 到 https://github.com 申請一個免費帳號（如果還沒有）
2. 建立一個新的 repository（可以設成 Private，只有你自己看得到程式碼）
3. 把這個資料夾裡的 `app.py` 和 `requirements.txt` 上傳上去
4. 到 https://share.streamlit.io 用 GitHub 帳號登入
5. 點「New app」，選剛剛那個 repository、分支 `main`、檔案選 `app.py`
6. 部署前先設密碼：進入 App 的 Settings → Secrets，貼上：
   ```
   APP_PASSWORD = "你想要的密碼"
   ```
7. 按下部署，等一兩分鐘，就會拿到一個網址（例如
   `https://your-app-name.streamlit.app`），這個網址就是給同事用的，
   同事打開後要先輸入你設的密碼才能用

之後你要更新程式（例如改欄位邏輯），只要更新 GitHub 上的 `app.py`，
Streamlit Cloud 會自動重新部署，網址不會變。

## 本機測試（建議正式上線前先在自己電腦測一次）

```bash
pip install -r requirements.txt
streamlit run app.py
```

會在瀏覽器開一個 `localhost` 網址，可以先用真實 Excel 檔案測試看看
欄位對不對、篩選邏輯跑不跑得動。本機測試不用設密碼，沒設
`APP_PASSWORD` 的話程式會直接放行。

## ⚠️ 機型分類 / 零件分類，之後怎麼增加內容

兩份分類表現在都內嵌在 `app.py` 裡（`MODEL_RECORDS` 和
`CODE_TO_CATEGORY` / `NAME_TO_CATEGORY` / `KNOWN_CATEGORIES` /
`NAME_OVERRIDES`），**不是你自己能在網頁上加的**。之後如果：
- 機型分類表有新增/修改 → 把新的「機型分類_已填寫.xlsx」給我，我重新
  產生 `MODEL_RECORDS`
- 零件分類規則有新增/修改（像這次的冷媒、外殼分類修正）→ 直接列給我
  「品名清單 + 要歸類到哪一類」，我加進 `NAME_OVERRIDES`，不用整份表
  重來

改完你重新上傳 GitHub 覆蓋、Streamlit Cloud 就會自動重新部署。

## ⚠️ 零件料號在故障率頁面目前還是單一鎖定邏輯的多選版

「零件料號」在故障率頁面的鎖定條件（類別/機型/故障部位都選了才開放）
沿用之前的邏輯，只是判斷方式從「字串是否為'全部'」改成「list是否為空」。
如果之後這個鎖定邏輯本身要再調整，跟我說一聲即可。

## ⚠️ 還沒解決的事

累積出貨量只能抓到「年度」粒度（出貨資料是一年一欄，不是按月），細節
在 `rate_table` 附近的註解與頁面提示文字裡。

## 密碼保護的限制

這個密碼是「共用密碼」，同事都用同一組密碼登入，不是每人一個帳號。
如果之後想要有登入紀錄、每人各自的帳號密碼，需要額外的身份驗證機制，
這支程式目前沒有做這塊。
