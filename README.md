# 零件耗用 / 故障率查詢工具

## 部署到 Streamlit Community Cloud（免費、給同事一個網址用）

1. 到 https://github.com 申請一個免費帳號（如果還沒有）
2. 建立一個新的 repository（可以設成 Private，只有你自己看得到程式碼）
3. 把這個資料夾裡的 `app.py` 和 `requirements.txt` 上傳上去
4. 到 https://share.streamlit.io 用 GitHub 帳號登入
5. 點「New app」，選剛剛那個 repository、分支 `main`、檔案選 `app.py`
6. 部署前先設密碼：進入 App 的 Settings → Secrets，貼上：
   ```
   APP_PASSWORD = "你想要的密碼"
   ```
7. 按下部署，等一兩分鐘，就會拿到一個網址（例如
   `https://your-app-name.streamlit.app`），這個網址就是給同事用的，
   同事打開後要先輸入你設的密碼才能用

之後你要更新程式（例如改欄位邏輯），只要更新 GitHub 上的 `app.py`，
Streamlit Cloud 會自動重新部署，網址不會變。

## 本機測試（建議正式上線前先在自己電腦測一次）

```bash
pip install -r requirements.txt
streamlit run app.py
```

會在瀏覽器開一個 `localhost` 網址，可以先用真實 Excel 檔案測試看看
欄位對不對、篩選邏輯跑不跑得動。本機測試不用設密碼，沒設
`APP_PASSWORD` 的話程式會直接放行。

## ✅ 已用真實資料測試過（2026/08）

用你提供的 `2021-0630_故障耗用清單.xlsx`、`20260701-0731單月故障耗用清單.xlsx`、
`販售量_20210101-20260731.xlsx` 三份真實檔案，實際跑過完整的資料清理、
欄位對應、篩選、聚合邏輯，結果合理（機型 join 成功率 100%、分公司判讀
正常、零件耗用一覽/故障率計算都能跑出數字）。過程中發現並修正了幾個
跟原本規劃不同的地方，寫在 `app.py` 最上方的說明裡，其中最關鍵的一點：

> **「故障部位」欄位，耗用資料裡本來就有（例如 "C02 控制PCB"），
> 不是透過「零件分類一覽表」的 31 種「分類」去對應。**
> 這跟稍早討論時的假設不同，請務必確認這樣理解是對的。

## ⚠️ 還有兩個尚未解決、需要你決定的事

1. **累積出貨量只能抓到「年度」粒度**（出貨資料是一年一欄，不是按月），
   所以累積故障率算出來的分母，中間月份無法精確到月底，細節寫在
   `rate_table` 函式附近的註解與畫面提示文字裡。
2. **「故障部位」欄位裡有複合值**（例如「C02 控制PCB、E01 熱交換器」
   用頓號分隔），目前當成一個獨立組合值處理，沒有拆開成兩筆分開計算。
   如果要讓一列同時算進兩個故障部位的統計，需要再調整聚合邏輯。

## 密碼保護的限制

這個密碼是「共用密碼」，同事都用同一組密碼登入，不是每人一個帳號。
如果之後想要有登入紀錄、每人各自的帳號密碼，需要額外的身份驗證機制，
這支程式目前沒有做這塊。
